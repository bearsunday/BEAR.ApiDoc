# BEAR.ApiDoc

[English](README.md)

BEAR.ApiDocはアプリケーションからAPIドキュメントを生成します。

メソッドシグネチャ、PHPDoc、JSON Schemaから生成されるドキュメントは、実際のアプリケーションと常に一致します。

IDLを書く手間が省けるだけでなく、正確なドキュメントを生成できます。

## デモ

[ライブデモ](https://bearsunday.github.io/BEAR.ApiDoc/)

## インストール

    composer require bear/api-doc ^1.0

## 使い方

[APIドキュメント](http://bearsunday.github.io/manuals/1.0/ja/apidoc.html)を参照してください。
