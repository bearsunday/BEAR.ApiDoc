ALPS Profiles

Application-level Profile Semantics (ALPS) profiles for this documentation. The structural profiles describe the vocabulary of the generated reports; they are declared by each page via rel="profile". The rendered application profile is at alps.html.

apidoc.xml
Structural profile for the main API documentation (index.html): endpoint, response, method, rel, embed, object, array, param, and related descriptors.
terms.xml
Profile for the Term Usage Index (terms.html): term, alpsBacked, usage (parameterUsage / schemaPropertyUsage), reservedField, and coverage figures.
audit.xml
Profile for the Documentation Audit (audit.html): apiDocumentationAudit, operation, finding, findingType, and summary counts.
index-schema.xml
Profile for the JSON Schema index.
